# 数据结构

本目录记录数据结构相关笔记。

讲解原则：

- 使用 C/C++ 结构体、函数或伪代码表示数据结构与算法；不强制纯 C，必要时使用适量 C++ 特性降低表达复杂度。
- C++ 示例以直观、贴近408答题为原则，避免为了炫技引入与考点无关的复杂语法。
- 展示关键步骤中容器、指针、下标和变量的实际变化。
- 同时记录时间复杂度、空间复杂度、边界条件和易错点。
